# Guide

## Definition

The first-run prompt and agent that asks how the user wants the app to look, and then builds it.

## Attributes

- Implementation: proposed as an ordinary harness session using the public API.
- Tome: proposed to drive the guide when installed, with a simpler default otherwise.

## Relationships

- [[session]]: the guide proposed to run as one.
- [[plugin]]: builds what is missing.
- [[tome]]: can power the guide.
